# Contributing to Sasol Rewards Dashboard

Thank you for your interest in contributing to this project.

## Getting Started

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your updates and test them locally.
4. Commit your changes with a clear commit message.
5. Push your branch to GitHub.
6. Create a Pull Request (PR).

## Coding Standards

- Use clean and readable HTML, CSS, and JavaScript.
- Keep code properly formatted and indented.
- Use meaningful variable and function names.
- Remove unused code before submitting.

## Reporting Issues

If you find a bug or have a feature suggestion:

1. Open an Issue.
2. Provide a clear description.
3. Include steps to reproduce the problem.
4. Add screenshots if applicable.

## Pull Request Guidelines

- Describe the purpose of your changes.
- Keep PRs focused on a single improvement.
- Ensure existing functionality is not broken.
- Update documentation when necessary.

## Dashboard Improvements

Contributions are welcome for:

- UI/UX enhancements
- Performance improvements
- Bug fixes
- New dashboard features
- Reporting and analytics enhancements

## Code of Conduct

Be respectful and professional when collaborating with others.

Thank you for helping improve the Sasol Rewards Dashboard!
